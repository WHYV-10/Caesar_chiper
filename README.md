# Caesar Cipher
Aplikasi enkripsi dan dekripsi **Caesar Cipher** berbasis GUI, dibuat dengan Python dan Tkinter.
## Tentang Caesar Cipher
Caesar Cipher adalah cipher substitusi. Setiap huruf pada teks digeser sebanyak N posisi di dalam alfabet. Angka N inilah yang menjadi kunci.

Contoh dengan kunci 3: `A` menjadi `D`, `B` menjadi `E`, dan seterusnya.

## Fitur
- Enkripsi dan dekripsi teks
- Kunci berupa angka
- Pratinjau pemetaan alfabet yang berubah sesuai kunci
- Tombol salin hasil ke clipboard
- Huruf besar/kecil dan tanda baca tetap dipertahankan

## Cara Menjalankan
Pastikan Python 3 sudah terpasang (Tkinter sudah termasuk di Python).
